用户可以使用 [listReplicaGroups()](/cn/sequoiadb-cat_id-1432190799-edition_id-304) 监控集群状态。

  1. 连接到协调节点：
         
         $ /opt/sequoiadb/bin/sdb
         > var db = new Sdb( "localhost", 11810 )

  2. 集群状态：
         
         > db.listReplicaGroups()
