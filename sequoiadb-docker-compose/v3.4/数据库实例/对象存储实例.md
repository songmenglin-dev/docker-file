SequoiaDB 除了支持创建关系型数据库实例和 JSON 实例外，同样支持创建 S3 对象存储实例。

S3 对象存储实例适用于对象存储类的实时处理与归档类场景，SequoiaDB 与 S3 保持协议级兼容。SequoiaS3 系统实现通过 AWS S3 接口访问 SequoiaDB 的能力。
