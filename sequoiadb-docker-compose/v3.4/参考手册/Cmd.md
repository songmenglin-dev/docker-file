Cmd 类主要用于创建和操作 cmd 对象，包含的函数如下：

名称 | 描述  
---|---  
[Cmd()](/cn/sequoiadb-cat_id-1557112070-edition_id-304) | 新建一个 Command 对象  
[getCommand()](/cn/sequoiadb-cat_id-1557112303-edition_id-304) | 获取上次执行的命令  
[getInfo()](/cn/sequoiadb-cat_id-1557112309-edition_id-304) | 获取 Command 对象的对象信息  
[getLastOut()](/cn/sequoiadb-cat_id-1557112311-edition_id-304) | 获取上次命令执行的返回结果  
[getLastRet()](/cn/sequoiadb-cat_id-1557112323-edition_id-304) | 获取上次命令执行返回的错误码  
[run()](/cn/sequoiadb-cat_id-1557112332-edition_id-304) | 执行 Shell 指令  
[runJS()](/cn/sequoiadb-cat_id-1557112341-edition_id-304) | 远程执行 JavaScript 代码  
[start()](/cn/sequoiadb-cat_id-1557112346-edition_id-304) | 后台执行 Shell 指令
