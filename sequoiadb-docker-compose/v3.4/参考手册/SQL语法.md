SequoiaDB 巨杉数据库支持通过 SQL 语法进行数据库操作，本章主要内容如下：

  * [语句](/cn/sequoiadb-cat_id-1510279692-edition_id-304)：对数据库进行操作的一种语言
  * [子句](/cn/sequoiadb-cat_id-1510279691-edition_id-304)：语句和查询的组成部分
  * [函数](/cn/sequoiadb-cat_id-1510279690-edition_id-304)：SequoiaDB 支持使用部分聚合函数实现数据分析
  * [监控视图](/cn/sequoiadb-cat_id-1559282734-edition_id-304)：监视当前系统状态
  * [表达式](/cn/sequoiadb-cat_id-1510279628-edition_id-304)：SequoiaDB 支持算数表达式和比较表达式
  * [运算符](/cn/sequoiadb-cat_id-1520813531-edition_id-304)：SequoiaDB 支持算术运算符、比较运算符和逻辑运算符
  * [数据类型](/cn/sequoiadb-cat_id-1450171368-edition_id-304)：SequoiaDB 支持的数据类型包括整数、长整数、浮点数、字符串、日期、时间戳、对象 ID和高精度数
