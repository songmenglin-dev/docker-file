Ssh 类主要用于连接主机，包含的函数如下：

名称 | 描述  
---|---  
[Ssh()](/cn/sequoiadb-cat_id-1561538063-edition_id-304) | 使用 SSH 方式连接主机  
[close()](/cn/sequoiadb-cat_id-1561538064-edition_id-304) | 关闭 Ssh 连接  
[exec()](/cn/sequoiadb-cat_id-1561538065-edition_id-304) | 执行 Shell 指令  
[getLastOut()](/cn/sequoiadb-cat_id-1561538066-edition_id-304) | 获取上次命令执行的返回结果  
[getLastRet()](/cn/sequoiadb-cat_id-1561538067-edition_id-304) | 获取上次命令执行返回的错误码  
[getLocalIP()](/cn/sequoiadb-cat_id-1561538068-edition_id-304) | 获取本地 IP 地址  
[getPeerIP()](/cn/sequoiadb-cat_id-1561538069-edition_id-304) | 获取远程主机的 IP 地址  
[pull()](/cn/sequoiadb-cat_id-1561538070-edition_id-304) | 从远程主机复制文件到本地  
[push()](/cn/sequoiadb-cat_id-1561538071-edition_id-304) | 从本地主机上复制文件到远程主机上
